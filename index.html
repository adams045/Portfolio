CommercePlex — E-Commerce Microservices Platform
In Development
An 8-service e-commerce backend built to tie together everything I know: Auth, Catalog, Order, Payment, Inventory Sync, Notification, AI Content Generation, and Search — communicating asynchronously via Apache Artemis instead of direct service-to-service calls.
Java 21Spring BootApache Artemis RedisMySQLElasticsearch OpenAI APIJWTDocker
Challenge

Most portfolio projects are single monoliths. I wanted a project that actually demonstrates service boundaries, event-driven communication, and the operational thinking that comes with running independent services.

Approach

Each service owns its own database. Services never call each other directly — they publish and subscribe to events on Apache Artemis (OrderPlaced, PaymentCompleted, StockUpdated). Inventory uses Redis distributed locks to prevent overselling. Everything is containerized with Docker Compose behind a single API Gateway.

Architecture
Amber lines = async event flow through the Artemis broker · each node is an independently deployable service
